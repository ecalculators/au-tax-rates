# Australian tax and super rates, 2026-27

Australian income tax brackets, Medicare levy surcharge tiers, HELP repayment thresholds and the main super rates and caps for the 2026-27 income year, as one dated, sourced dataset.

- `rates-2026-27.json`: all rates with metadata
- `rates-2026-27.csv`: the same rates, one row each

Each row carries its value, unit, tax year, the ATO page it comes from and the date it was last checked against that page. Rates are checked against the ATO every week and this dataset is updated when a figure changes.

## Coverage
- Resident individual income tax brackets (excluding the Medicare levy)
- Medicare levy and Medicare levy surcharge tiers (single and family)
- HELP (study loan) repayment tiers
- Super guarantee rate and maximum contribution base
- Concessional and non-concessional contribution caps, and the carry-forward total super balance limit
- Division 293 threshold and rate
- Division 296 thresholds
